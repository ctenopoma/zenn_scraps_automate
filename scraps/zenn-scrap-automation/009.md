## 追記：API キーの発行画面は 404 だった

ログインした状態で `https://zenn.dev/settings/api-keys` を開いてみたところ、**404** だった。

- [Zenn のお知らせ・リリースノート](https://info.zenn.dev/)にも、Public API や API キーの告知はまだない。
- zenn-cli の PR にも、どんなユーザーがキーを発行できるのかは書かれていない。
- API 自体は本番で動いている。ただし、キーを発行できるのは今のところ運営側か一部のアカウントだけのようだ（推測）。

というわけで、**公式 API は「将来の本命」に格下げ**する。ツールは投稿経路（transport）を差し替えられる作りにしておく。

- `public-api` … 開放されたらこれに切り替える
- `internal-api` … Cookie を使う非公式 API
- `browser` … ユーザースクリプトから同一オリジンで fetch する

当面どの経路を使うかを、次に決める。
