## 大発見：zenn-cli に Scrap 用の Public API が入っていた

zenn-editor のソースを読んでいて見つけた。**zenn-cli 0.5.3（2026-08-26）以降**に、実験的な `zenn scrap` コマンドがある。

```sh
export ZENN_CLI_EXPERIMENTAL_SCRAP_API=true
export ZENN_API_KEY=...   # scrap:read / scrap:write
npx zenn scrap create --title "作業メモ" --file ./scrap.md
npx zenn scrap post <slug> --file - --reply-to <comment_slug>
```

- ベースURL は `https://zenn.dev/api/public-api/v1`。認証は `Authorization: Bearer`。
- できること：作成、コメント、返信、編集、一覧、取得、更新（close / archive / topics）。canary ではさらに削除と画像アップロード。
- 未認証で GET すると 401 が返る。エンドポイントは本番に存在している。
- 開発者のスクラップは `"posting_route":"api"` と記録されていた。**API 経由の投稿は、運営から見て正規ルート**ということ。
- 失敗時に POST を再試行しない作りになっている。重複投稿の対策として、自作するときも真似したい。
