## 候補1：非公式の内部API（Cookie認証）

[katzumiさんのキャプチャ](https://zenn.dev/katzumi/scraps/a0357c5de7b3ea)（2023-11）によると、エンドポイントは次のとおり。

| 操作 | リクエスト |
|---|---|
| 作成 | `POST /api/scraps` `{"title":...}` |
| コメント | `POST /api/comments` `{"commentable_type":"Scrap","commentable_id":<数値id>,"body_markdown":...}` |
| 返信 | 上記に `parent_id` を追加 |
| アーカイブ | `PUT /api/scraps/{slug}` |
| 削除 | `DELETE /api/scraps/{slug}` |

- 認証は `_zenn_session` / `remember_user_token` の Cookie（Rails + Devise）。
- 読み取りは `GET /api/scraps/{slug}`（認証不要、`body_html` のみ）と、`/blob.json`（要ログイン、`body_markdown` が取れる）。

**良い点**
- 速い。
- トークン消費ほぼ0。
- 本文が変わらない。

**悪い点**
- 非公式なので、予告なく変わる。
- Cookie はアカウントの全権を持つ。
- ログインは Google かメールのみなので、自動ログインはほぼ無理。Cookie は手でコピーすることになる。
- 投稿まで行う公開ツールは見つからなかった。読み取り用の [zenn-scrap-to-md](https://github.com/ackkerman/zenn-scrap-to-md) はある。
